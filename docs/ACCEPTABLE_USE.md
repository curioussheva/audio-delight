# PristineAudio - Acceptable Use

Batas penggunaan yang sah. Ditujukan untuk ditampilkan ke pengguna.

---

## 1. Tujuan Aplikasi

PristineAudio adalah **pemutar audio lokal untuk Android** dengan tujuan bit-perfect playback: memutar file audio milik pengguna sendiri dengan jalur sinyal sesingkat mungkin, plus dukungan USB DAC, equalizer, dan visualizer.

Aplikasi ini **tidak** menyediakan, mengunduh, atau mendistribusikan konten audio apa pun.

## 2. Tanggung Jawab Pengguna

**File yang Anda putar adalah tanggung jawab Anda.** PristineAudio tidak memverifikasi asal-usul, lisensi, atau legalitas file audio yang Anda tambahkan ke library.

Anda bertanggung jawab memastikan bahwa:

- Anda memiliki hak untuk memutar file audio yang ada di perangkat Anda
- Anda tidak menggunakan aplikasi ini untuk memutar konten yang diperoleh secara melanggar hukum di wilayah Anda

## 3. Batasan Developer

Aplikasi ini dirancang untuk:

- Memutar audio yang sudah ada di perangkat
- Membaca metadata dan artwork dari file itu sendiri
- Tidak mengumpulkan, mengirim, atau menjual data pengguna

Aplikasi ini **tidak**:

- Menyediakan katalog, pencarian, atau streaming konten berhak cipta
- Melewati atau menembus DRM
- Menghubungi server apa pun untuk mendapatkan konten

**Catatan jujur:** manifest mendeklarasikan izin `INTERNET` meskipun tidak ditemukan fitur jaringan yang jelas di kode. Lihat `PRIVACY.md` bagian 3 dan `THREAT_MODEL.md` bagian 5. Ini sedang ditinjau, bukan fitur.

## 4. Pelaporan Masalah

Keamanan dan privasi: laporkan lewat issue tracker repo.

## 5. Persetujuan

Dengan menggunakan PristineAudio, Anda memahami bahwa aplikasi ini adalah alat pemutar lokal tanpa layanan konten, dan bahwa tanggung jawab atas isi library Anda sepenuhnya ada pada Anda.
